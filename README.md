# PantryChef

## Запуск

Нужны **Node.js 22+** и телефон с Expo Go (SDK 57).

```bash
cd pantrychef
npm install
npx expo start
```

Отсканируйте QR в Expo Go (Android / iOS).

## Что уже есть

- Стартовый опросник: аллергии, рацион, любимые кухни, острота, нелюбимые продукты
- Холодильник: ручной ввод ингредиентов
- Генерация персональных рецептов через OpenAI по продуктам и предпочтениям
- Экран скана фото (камера / галерея) с готовым `VisionAdapter`
- Настройки API-ключей

## Генерация рецептов

Подбор рецептов отправляет продукты, язык приложения и предпочтения на `/api/openai`, который генерирует рецепты с учётом аллергий, диеты, любимых кухонь и уровня остроты. Ключ OpenAI хранится только в переменной окружения сервера `OPENAI_API_KEY` (например, в Vercel), а не в приложении. Для локальной разработки запустите API с этой переменной и укажите адрес локального сервера в `src/lib/openai.ts`.

## Апгрейд под фото холодильника

Уже сделано:

1. Вкладка **Скан** снимает или выбирает фото
2. Интерфейс `VisionAdapter` в `src/vision/index.ts`
3. Готовый адаптер OpenAI Vision (`gpt-4o-mini`)
4. Распознанные продукты падают в тот же холодильник с пометкой «с фото»

Чтобы включить:

1. Возьмите ключ OpenAI
2. Настройки → показать поля ключей → **OpenAI key**
3. Сфотографируйте холодильник → «Распознать продукты»

Другой ИИ (Gemini, свой бэкенд) подключается новым классом с тем же интерфейсом `detectFromImage(imageUri)` и выбором в `createVisionAdapter`.

Ключи хранятся только на устройстве (AsyncStorage), не улетают на наш сервер.
